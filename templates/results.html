Predicting mileage (regression)

Each model predicts the mileage in {{ m.unit }}. R² closer to 1 and a smaller error are better. The best model is the one with the highest cross-validated R², which is steadier than one test split.

Why {{ reg.best }} is marked best. It has the highest cross-validated R² ({{ '%.3f' % reg.models[0].cv_r2 }}), which averages five different train/test splits instead of trusting one. {% if reg.models | length > 1 %}The runner-up, {{ reg.models[1].name }}, scores {{ '%.3f' % reg.models[1].cv_r2 }}, so the top models are close and the winner can change if the data changes.{% endif %} Train R² is how well a model fits the rows it learned from. Test R² is how well it does on new rows. A big gap between them means the model memorised its training data.
